28 DAYS: CLASSROOM EDITION
==========================

A game about the menstrual cycle for middle school health classes.

To play:           double-click index.html
For teachers:      double-click teacher-guide.html (it prints well)
Where facts are from: SOURCES.md

Nothing to install and no accounts. It needs a keyboard, so it does not work
on phones. It collects no information about students.

This is a separate copy of the game, changed for classroom use. The original
game is not affected by anything in this folder.

Please have a school nurse or health teacher review it before using it with
students. It is not medical advice.
